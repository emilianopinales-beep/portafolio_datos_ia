# Selección de características y predicción de desempeño estudiantil

Preparación de datos, selección de variables y regresión lineal múltiple

## Descripción

Se revisan faltantes, duplicados y atípicos; se estudian correlaciones, se seleccionan características y se evalúa un modelo con datos de entrenamiento y prueba.

## Fuente y características de los datos

**Fuente:** [UCI Machine Learning Repository — Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance)

Conjunto de 395 registros y 10 variables académicas y demográficas; la variable objetivo es la calificación final G3.
