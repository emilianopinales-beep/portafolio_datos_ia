# Portafolio de análisis de datos y regresión

Este repositorio reúne proyectos reproducibles de análisis de datos desarrollados en Python. El portafolio muestra habilidades en exploración y preparación de datos, visualización, regresión, selección de características, evaluación predictiva e inferencia estadística.

## Índice de proyectos

1. [Exploración de factores asociados a obesidad](01-obesidad/)
2. [Regresión y factores asociados a la felicidad](02-felicidad-regresion/)
3. [Selección de características y predicción de desempeño estudiantil](03-desempeno-estudiantil/)
4. [Predicción del gasto monetario de hogares en México](04-gasto-hogares/)

## Navegación web

La página principal del portafolio está en [`index.html`](index.html). Cada proyecto cuenta con su propia página, README, notebook Jupyter y reporte HTML.

## Herramientas

Python · Jupyter Notebook · pandas · NumPy · matplotlib · scikit-learn · statsmodels
