# Portafolio de análisis de datos e inteligencia artificial

Repositorio de proyectos realizados en Python para la materia de Inteligencia Artificial.
Contiene trabajos de análisis exploratorio, regresión, selección de características, clasificación, evaluación de modelos, reducción de dimensionalidad y sistemas de recomendación.

## Herramientas

Python · Jupyter Notebook · pandas · NumPy · matplotlib · scikit-learn · statsmodels · seaborn · fancyimpute

## Datos

Los proyectos 04 a 07 utilizan microdatos de la ENIGH 2024 del INEGI. Para volver a ejecutar los proyectos 05, 06 y 07, se necesita descargar `concentradohogar.csv` desde las fuentes oficiales y colocarlo junto al notebook. El proyecto 08 utiliza datasets de scikit-learn y MovieLens 100k. Los archivos HTML pueden visualizarse sin descargar los datasets.
