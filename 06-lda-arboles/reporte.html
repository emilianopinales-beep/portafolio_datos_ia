1. Introducción¶

En esta actividad se comparan dos metodologías diferentes para resolver un problema de clasificación: Linear Discriminant Analysis (LDA) y árboles de decisión.

Se utilizarán datos de la Encuesta Nacional de Ingresos y Gastos de los Hogares 2024 (ENIGH). El problema consiste en clasificar a los hogares según presenten un nivel de gasto corriente monetario bajo o alto, utilizando como punto de corte la mediana de gasto_mon.

El objetivo es construir ambos modelos sobre el mismo problema, analizar su comportamiento, evaluar su desempeño mediante distintas métricas y determinar cuál resulta más adecuado para esta tarea.

2. Definición del problema de clasificación¶

En el proyecto anterior, la variable de respuesta gasto_mon representó el gasto corriente monetario trimestral del hogar como una variable cuantitativa continua.

Para transformar el problema en uno de clasificación binaria, se utilizará la mediana del gasto corriente monetario como punto de corte. Los hogares con un gasto igual o menor a la mediana serán clasificados como gasto bajo (0), mientras que los hogares con un gasto superior a la mediana serán clasificados como gasto alto (1).

El uso de la mediana permite establecer un criterio basado directamente en la distribución observada de los datos y ayuda a obtener clases aproximadamente equilibradas, lo cual facilita la evaluación del modelo y evita que una clase tenga una representación considerablemente mayor que la otra.

3. Preparación de los datos y separación entrenamiento-prueba¶

Se utilizarán como variables explicativas características económicas, demográficas y del hogar que ya fueron consideradas en el proyecto anterior y que no corresponden directamente al gasto utilizado para construir la variable de salida.

Las variables numéricas consideradas son el ingreso corriente, número de integrantes, número de personas ocupadas, número de perceptores de ingreso y edad del jefe del hogar. El ingreso se transformará mediante logaritmo debido a su elevada asimetría observada en el análisis anterior.

También se utilizarán como variables categóricas la educación y sexo del jefe del hogar, el tamaño de localidad, el estrato socioeconómico y la clase de hogar.

El conjunto de datos se dividirá en 80 % para entrenamiento y 20 % para prueba. La división será estratificada para conservar la misma proporción de las clases en ambos subconjuntos.

4. Modelo basado en Linear Discriminant Analysis (LDA)¶

LDA busca una combinación lineal de las variables de entrada que permita separar las clases. Este método supone que las variables utilizadas presentan una distribución aproximadamente normal dentro de cada clase y que las clases comparten una estructura de covarianza similar.

Para mantener mayor coherencia con estos supuestos se consideran únicamente las variables cuantitativas del problema. Las variables categóricas no se incorporan directamente al modelo LDA.

Antes de ajustar el modelo se revisará la asimetría de las variables cuantitativas dentro de cada clase. Se dará preferencia a aquellas con menor asimetría, debido a que presentan un comportamiento más compatible con los supuestos del modelo.

5. Modelo basado en árboles de decisión¶

El segundo enfoque es un árbol de decisión. A diferencia de LDA, este modelo no requiere asumir una frontera lineal ni una distribución normal de las variables.

Para el árbol se utilizarán tanto las variables numéricas como las variables categóricas. Las variables categóricas se transformarán mediante codificación one-hot.

Se utilizará random_state=42 para garantizar resultados reproducibles y min_samples_leaf=200 para evitar reglas construidas a partir de grupos excesivamente pequeños.

Posteriormente se realizará poda por complejidad de costo mediante el parámetro ccp_alpha. Un valor mayor de α produce un árbol más simple al eliminar divisiones cuya mejora no compensa el aumento de complejidad.

5.1 Selección del parámetro de poda α¶

Primero se construye un árbol sin poda por complejidad de costo para obtener los posibles valores de ccp_alpha.

Posteriormente se evalúa una selección representativa de estos valores mediante validación cruzada estratificada de cinco particiones utilizando F1-score.

Para seleccionar α se utiliza la regla de un error estándar: entre los modelos cuyo desempeño se encuentra suficientemente cerca del mejor resultado de validación, se elige el valor de α más grande. De esta forma se favorece un árbol más sencillo sin sacrificar de manera importante su capacidad de clasificación.

    y_train

alphas_disponibles = np.unique(
    ruta_poda.ccp_alphas
)

# Se elimina el último valor, que normalmente deja solo la raíz
if len(alphas_disponibles) > 1:
    alphas_disponibles = alphas_disponibles[:-1]

# Para hacer eficiente la validación se prueban hasta 15 valores
if len(alphas_disponibles) > 15:
    posiciones = np.linspace(
        0,
        len(alphas_disponibles) - 1,
        15
    ).astype(int)

    alphas = np.unique(
        alphas_disponibles[posiciones]
    )
else:
    alphas = alphas_disponibles

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

resultados_alpha = []

for alpha in alphas:

    modelo_temp = DecisionTreeClassifier(
        random_state=42,
        min_samples_leaf=200,
        ccp_alpha=alpha
    )

    scores = cross_val_score(
        modelo_temp,
        X_train_arbol,
        y_train,
        cv=cv,
        scoring="f1",
        n_jobs=-1
    )

    resultados_alpha.append({
        "alpha": alpha,
        "F1_promedio": scores.mean(),
        "Desv_estandar": scores.std()
    })
