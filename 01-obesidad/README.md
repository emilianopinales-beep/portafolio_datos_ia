# Exploración de factores asociados a obesidad

Análisis exploratorio de variables demográficas, hábitos y nivel de obesidad

## Descripción

Se exploran tipos de variables, valores faltantes, estadísticas descriptivas y la distribución del nivel de obesidad. También se analiza una subpoblación masculina mediante visualizaciones.

## Fuente y características de los datos

**Fuente:** [UCI Machine Learning Repository — Estimation of Obesity Levels Based On Eating Habits and Physical Condition](https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition)

Conjunto con 2,111 registros y 10 variables sobre características físicas, hábitos y nivel de obesidad.
